## 📦 Installation

Clone the repository

```bash
git clone https://github.com/shiuly-28/my-portfoilo.git
```

Go to the project folder

```bash
cd my-portfoilo
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
